# Open-LLM-VTuber with Twitch Integration

Цей репозиторій містить налаштовану версію [Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber) з доданим модулем для інтеграції з Twitch.

## Особливості цієї збірки

1.  **Попередньо налаштований конфіг** (`open-llm-vtuber/conf.yaml`):
    *   Вже готовий до запуску.
    *   Використовує **Edge TTS** (якісний голос, безкоштовно).
    *   Налаштований на роботу з локальними LLM (наприклад, Ollama) або OpenAI-сумісними API.
2.  **Інтеграція з Twitch**:
    *   Додано скрипт `run_twitch.py`, який читає чат вашого каналу.
    *   Повідомлення глядачів передаються аватару як голосові команди.

## Як запустити (на вашому ПК)

### 1. Підготовка

Вам знадобиться Python 3.10 або новіше.

1.  Встановіть залежності:
    ```bash
    cd open-llm-vtuber
    pip install -r requirements.txt
    ```

### 2. Налаштування Twitch

Відкрийте файл `open-llm-vtuber/conf.yaml` і знайдіть секцію `twitch_live` в самому кінці файлу:

```yaml
  twitch_live:
    channel_name: "ВАШ_КАНАЛ"       # Наприклад: "xqc"
    bot_username: "ВАШ_БОТ"         # Ім'я акаунта, який буде читати чат (можна ваше власне)
    oauth_token: "oauth:..."        # Токен доступу
```

Щоб отримати `oauth_token`, перейдіть на [twitchapps.com/tmi/](https://twitchapps.com/tmi/), авторизуйтесь під акаунтом бота і скопіюйте рядок (починається з `oauth:`).

### 3. Запуск

Вам потрібно запустити **два** процеси в різних терміналах:

**Термінал 1: Основний сервер (Мозок аватара)**
```bash
cd open-llm-vtuber
python run_server.py
```
Зачекайте, поки з'явиться повідомлення `Uvicorn running on http://localhost:12393`. Після цього ви можете відкрити цю адресу в браузері, щоб бачити аватара.

**Термінал 2: Twitch Клієнт (Вуха аватара)**
```bash
cd open-llm-vtuber
python run_twitch.py
```
Якщо налаштування правильні, ви побачите повідомлення `Connected to Twitch channel`. Тепер все, що пишуть у чаті, буде озвучуватися і оброблятися аватаром!

## Примітка

Якщо ви хочете змінити модель ШІ (LLM), відредагуйте `conf.yaml` (секція `llm_configs`). За замовчуванням там стоїть `openai_compatible_llm`, налаштований на локальний сервер (Ollama).
